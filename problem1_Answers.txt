Problem 1 Answers

Q1.1
SQL:
USE company;
DELETE FROM EMPLOYEE WHERE ssn='204518837';

Output:
ERROR 1451 (23000): Cannot delete or update a parent row: a foreign key constraint fails (`company`.`department`, CONSTRAINT `department_ibfk_1` FOREIGN KEY (`mgr_ssn`) REFERENCES `employee` (`ssn`))

Explanation:
The employee is the manager of a department, so DEPARTMENT.mgr_ssn still references it. MySQL rejects the delete to keep referential integrity.


Q1.2
SQL:
INSERT INTO PROJECT (Pnumber,Pname,Plocation,Dno) VALUES (104,'Test Project','Alexandria',99);

Output:
ERROR 1452 (23000): Cannot add or update a child row: a foreign key constraint fails (`company`.`project`, CONSTRAINT `project_ibfk_1` FOREIGN KEY (`Dno`) REFERENCES `department` (`Dnumber`))

Explanation:
Department 99 does not exist, so the foreign key value is neither NULL nor an existing primary key. MySQL rejects the insert.


Q1.3
SQL:
INSERT INTO EMPLOYEE VALUES ('900000001','Test',10);
INSERT INTO DEPARTMENT VALUES (10,'TestDept','900000001');
-- both fail with ERROR 1452
SET FOREIGN_KEY_CHECKS=0;
INSERT INTO DEPARTMENT VALUES (10,'TestDept','900000001');
INSERT INTO EMPLOYEE VALUES ('900000001','Test',10);
SET FOREIGN_KEY_CHECKS=1;
SELECT * FROM DEPARTMENT;
SELECT * FROM EMPLOYEE;

Output:
ERROR 1452 (23000): Cannot add or update a child row: a foreign key constraint fails (`test_q13`.`employee`, CONSTRAINT `employee_ibfk_1` FOREIGN KEY (`Dno`) REFERENCES `department` (`Dnumber`))
ERROR 1452 (23000): Cannot add or update a child row: a foreign key constraint fails (`test_q13`.`department`, CONSTRAINT `department_ibfk_1` FOREIGN KEY (`mgr_ssn`) REFERENCES `employee` (`ssn`))
After disabling the check:
DEPARTMENT: 10 | TestDept | 900000001
EMPLOYEE: 900000001 | Test | 10

Explanation:
The first row cannot be inserted normally because EMPLOYEE.Dno needs an existing department and DEPARTMENT.mgr_ssn needs an existing employee (circular dependency).
Solutions: (1) make one column nullable, insert NULL, then UPDATE it later (what I did in problem1_DML.sql); (2) SET FOREIGN_KEY_CHECKS=0, insert both rows, then SET FOREIGN_KEY_CHECKS=1; (3) create the tables without foreign keys, insert the data, then add the keys with ALTER TABLE.
